# OeziDev Cloud

Kendi sunucunda çalışan, OneDrive tarzı klasör eşitleme uygulaması — **OeziDev**.

## İndir
👉 **[En son sürüm (Windows 10/11)](https://github.com/OeziDev/oezidev-cloud/releases/latest)** — `OeziDev-Cloud-Setup-x.y.z.exe`

Kurduktan sonra uygulama kendini otomatik günceller.

## Özellikler
- Seçtiğin klasör buluta ve diğer bilgisayarlarına anında eşitlenir
- Saatin yanında durum ikonu ve son dosyalar paneli
- Çakışmada iki sürüm de korunur, toplu silmede önce sorar
- Dosya Gezgini entegrasyonu ve sağ tıkla paylaşım linki
- Sürüm geçmişi, çöp kutusu, web paneli

> Bu repo sadece kurulum dosyalarını dağıtır.
